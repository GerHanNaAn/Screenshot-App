# Screenshot App

Локальное приложение для создания и редактирования скриншотов. Внутреннее имя приложения — JoxiLite.

Можно выделить область экрана, снять окно или весь экран, добавить стрелки, рамки, текст и мозаику, скопировать результат в буфер обмена и сохранить PNG. История снимков хранится на компьютере пользователя. В исходниках приложения нет облачной загрузки снимков или встроенных учётных данных автора.

## Версии

- `main` — macOS: Swift / AppKit, сборка из исходников через `./build-mac.sh`.
- `ubuntu` — Ubuntu: Python / PySide6; запуск через `python3 main.py` после установки зависимостей из README ветки `ubuntu`. Это опубликованный рабочий снимок ветки; готовность на конкретном рабочем столе нужно проверить. При первом запуске создаются пользовательский launcher, пункт меню и автозапуск.

Готовые установщики в этот репозиторий не включены. Для macOS сборка использует локальную ad hoc подпись. Приложению требуется системное разрешение на захват экрана.

Исходники опубликованы с новой историей без личных адресов электронной почты и старых Git-метаданных. Локальные настройки, история снимков, бэкапы, виртуальные окружения и неопубликованные изменения исходного проекта не включены.

## Подробная инструкция


Локальное приложение для снимков экрана. На Ubuntu оно работает как программа в трее на Python и Qt 6. Снимки остаются на этом компьютере.

## Ubuntu

Нужны Python 3.10+, PySide6, портал рабочего стола и GStreamer (для снимка отдельного окна на Wayland):

```bash
sudo apt install python3-pyside6.qtcore python3-pyside6.qtgui python3-pyside6.qtwidgets python3-pyside6.qtsvg python3-pyside6.qtnetwork python3-dbus-next qt6-wayland gstreamer1.0-tools gstreamer1.0-pipewire gstreamer1.0-plugins-good
cd Screenshot-App
python3 main.py
```

Первый запуск ставит команду `~/.local/bin/joxilite`, пункт меню приложений и автозапуск. На GNOME Wayland система один раз спрашивает доступ к экрану. Разрешите показ в системном диалоге. Снимок всего рабочего стола делится по мониторам, и на каждом открывается свой редактор области.

Горячие клавиши по умолчанию: `Ctrl+Alt+2` — область, `Ctrl+Alt+3` — окно, `Ctrl+Alt+4` — экран под курсором, `Ctrl+Alt+5` — экран через 3 секунды. На Wayland GNOME подтверждает их в системном диалоге. Если диалог не появился, назначьте в «Параметры → Клавиатура» команду `joxilite --capture area`.

## macOS

Та же программа есть в виде приложения строки меню на Swift и AppKit, без сторонних библиотек. Работает на Apple Silicon и Intel с macOS 12 или новее.

## Возможности

- Снимок области (`⌘⇧2`), отдельного окна (`⌃⌥3`), экрана под курсором (`⌃⌥4`) или экрана с задержкой 3 секунды.
- Полноэкранный замороженный кадр для выбора области и её редактирования без перехода в отдельное окно (macOS 14 и новее).
- Стрелка, рамка, овал, линия, свободное перо, текст и мозаика для скрытия деталей.
- Синяя панель с горячими клавишами на кнопках и ручкой слева для перетаскивания.
- Ползунок толщины, полная палитра macOS (цветовой круг, RGB/HEX, пипетка и прозрачность).
- Ввод текста прямо на снимке с итоговым размером, настройками прозрачности и цветной подложки.
- Обрезка, масштаб, отмена и повтор действий.
- Копирование PNG в буфер обмена и сохранение PNG в исходном разрешении, включая Retina.
- Открытие PNG, JPEG, TIFF и HEIC для редактирования.
- Предупреждение при закрытии несохранённого снимка.
- Настройки глобальных сочетаний для трёх режимов захвата, клавиш восьми инструментов и поведения закрытия.
- Папка истории снимков с ограничением по общему размеру (по умолчанию 100 МБ).

## Сборка и запуск на macOS

Нужны бесплатные Apple Command Line Tools:

```bash
xcode-select --install
cd Screenshot-App
./build-mac.sh
open ~/Applications/JoxiLite.app
```

Если Command Line Tools уже установлены, первый шаг не нужен. Скрипт собирает единственную копию в `~/Applications/JoxiLite.app`. При желании добавьте её в «Системные настройки → Основные → Объекты входа». Перед повторной сборкой завершите JoxiLite.

При первом снимке macOS может запросить доступ к записи экрана. Разрешите его для JoxiLite в «Системные настройки → Конфиденциальность и безопасность → Запись экрана», затем перезапустите приложение. После повторной сборки с локальной ad hoc подписью macOS может попросить выдать доступ снова. Снимки никуда не отправляются.

## Работа

Выберите режим в меню значка камеры в строке меню или нажмите его глобальное сочетание. На macOS 14 и новее захват области показывает замороженный экран под курсором. Выделите область мышью; её можно двигать и менять за края и углы. Панель инструментов появляется на том же экране. Пометки остаются привязаны к исходному кадру при изменении области. `Esc` отменяет overlay на любом этапе. `Ctrl+C` или `⌘C` копирует выбранную область с пометками, сохраняет её в историю и закрывает overlay. Если запись истории не удастся, копия в буфере всё равно остаётся. Команда «Снять экран под курсором» открывает такой же overlay с выбранным экраном целиком. Команда «Снять окно» показывает список открытых окон. На macOS 12–13 используется стандартный интерактивный захват macOS и отдельный редактор.

Историю можно открыть из меню JoxiLite. Приложение удаляет старейшие снимки при превышении лимита папки; изменить лимит можно в настройках. Там же можно включить курсор в исходный снимок.

Горячие клавиши в редакторе: `⌘Z` — отменить, `⌘⇧Z` — повторить, `⌘C` — копировать PNG, `⌘S` — сохранить, `⌘O` — открыть изображение. Если `⌘⇧2` уже занят другим приложением, используйте команду в меню JoxiLite или назначьте другое сочетание в настройках.

Панель можно перетащить за ручку с точками слева. На кнопках показаны текущие назначения клавиш из настроек. Нажмите образец цвета, чтобы открыть палитру. Толщина линии регулируется ползунком от 1 до 30 пикселей.

Удерживайте `Shift` во время рисования: овал и рамка становятся залитыми, линия и стрелка привязываются к направлениям с шагом 45°, перо рисует прямой штрих, мозаика становится крупнее. При выделении области `Shift` задаёт квадрат, при её перемещении — движение по одной оси. Подсказка выбранного инструмента видна на панели.

Для текста нажмите на снимок и печатайте. Размер (10–96 px), непрозрачность букв, цвет и непрозрачность подложки меняют текущий текст сразу. `Enter` завершает ввод, `Shift+Enter` добавляет строку. Предпросмотр и сохранение используют один способ отрисовки, поэтому оформление не меняется после завершения ввода.

## Настройки

Откройте «Настройки…» в меню значка JoxiLite или нажмите `⌘,`. Нажмите на сочетание рядом с командой и введите новое; `Delete` снимает назначение, `Esc` отменяет запись. Для глобального снимка нужна буква или цифра с `⌘`, `⌃` или `⌥`. Инструментам редактора назначаются буквы или цифры без модификаторов; исходно используются `1`–`8`. Настройки действуют сразу и сохраняются между запусками.

По умолчанию `Esc` закрывает отдельный редактор. В настройках можно вернуть отмену текущего жеста вместо закрытия. Там же можно отключить вопросы о несохранённых снимках при закрытии редактора и выходе из приложения. Для полноэкранного overlay `Esc` всегда означает отмену. Кнопка «По умолчанию» восстанавливает исходные параметры.
